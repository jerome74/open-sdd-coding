# React

## Purpose
Typed and accessible React components in a Vite application.

## Instructions
Use React, TypeScript and existing Vite conventions. Build semantic reusable components, explicit typed props, form state and accessible interactions. Separate configuration from presentation. Avoid hardcoded prices and phone numbers. Handle missing images, invalid JSON and empty lists. Run existing build and tests.

## SDD alignment
Follow existing project SDD conventions and trace outputs to approved requirements. Never overwrite pre-existing configuration without approval.
