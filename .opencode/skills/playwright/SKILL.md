# Playwright

## Purpose
Browser exploration, DOM inspection, screenshots and repeatable tests.

## Instructions
Verify the Playwright MCP is configured and reachable. Inventory pages, sections, navigation, form states, desktop/mobile screenshots and interaction behavior. Record viewport, browser, URL and evidence. Prefer role-based locators; never submit live bookings. Test WhatsApp URLs without sending messages. Report blocked pages and tests actually run.

## SDD alignment
Follow existing project SDD conventions and trace outputs to approved requirements. Never overwrite pre-existing configuration without approval.
