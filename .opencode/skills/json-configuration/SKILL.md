# Json Configuration

## Purpose
Static JSON content models, validation and WhatsApp configuration.

## Instructions
Define stable IDs, categories, treatments, prices, durations, image paths and site contact settings. Validate required fields, positive prices and phone number in international digits. Use encodeURIComponent on the prefilled WhatsApp message. Never persist personal form data. Document JSON reload/rebuild behavior and provide fictional examples.

## SDD alignment
Follow existing project SDD conventions and trace outputs to approved requirements. Never overwrite pre-existing configuration without approval.
