# Visual Replication

## Purpose
Evidence-based screenshot comparison and UI fidelity iteration.

## Instructions
Capture reference and local screenshots with the same viewport, zoom, scroll position and UI state. Fix structure before micro-spacing. Check desktop and mobile separately. Record missing licensed assets and substitute only approved images. Do not invent visual fidelity scores or claim unexecuted tests. Ditto MCP is optional and must be verified first.

## SDD alignment
Follow existing project SDD conventions and trace outputs to approved requirements. Never overwrite pre-existing configuration without approval.
