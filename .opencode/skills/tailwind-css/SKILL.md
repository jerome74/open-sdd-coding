# Tailwind Css

## Purpose
Responsive visual styling using Tailwind CSS v4.

## Instructions
Use @tailwindcss/vite and @import "tailwindcss" in CSS. Do not require a Tailwind v3 config. Establish design tokens for typography, colors, spacing and radii. Match screenshots at fixed viewports. Validate mobile menu, focus states, reduced motion, text wrapping and image crop.

## SDD alignment
Follow existing project SDD conventions and trace outputs to approved requirements. Never overwrite pre-existing configuration without approval.
